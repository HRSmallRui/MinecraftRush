# MinecraftRush — 1.0 开源工程

这是 MinecraftRush 1.0 版本的完整游戏工程文件，使用 Godot 4.3 开发。  
下载后可直接导入 Godot 运行，适合用于学习和参考。

---

## 🎯 写在前面

这个项目对我来说，其实是一个等了很久的圆梦工程。

从初中开始，我就一直想做一款 Minecraft 和 KR 联动的塔防游戏。那时候脑子里有很多想法，甚至在本子上画过好几版草稿——怪物的设计思路、关卡的推进方式、KR 角色在 MC 风格下的呈现……什么都有。可惜当时什么都不会，所有想法都只能停留在纸面上。

高中那几年更是连碰电脑的时间都很少，那些草稿就一直压在抽屉里，偶尔翻出来看看，觉得“大概永远也做不出来了”。

直到上了大学，有了点时间，也终于鼓起勇气去学 Godot。从最基础的节点开始摸，一点点搭场景、写逻辑、改 bug。中间推翻重做过一次（也就是仓库里那个 Old 版本），但最后还是咬着牙把主线做完了。

现在回头看，这不仅仅是一个游戏工程，更是对当年那个只能在纸上画塔防的少年的一份交代。

---

## 📌 这是什么？

这是一个基于 Godot 制作的 KR 同人塔防游戏，包含完整的源代码、场景和美术资源。  
你可以用它来：

- 学习 Godot 塔防游戏的代码结构和工程组织方式
- 参考我的实现思路（技术有限，代码仅供参考）
- 在此基础上制作自己的 KR 同人作品

---
